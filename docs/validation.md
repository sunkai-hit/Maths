# 验证记录与边界

## 原始构建验证

执行 `node work/validate.mjs`：检查六章、26 个教材节次及六个复习入口有内容，题型与练习 ID 唯一，每题型有三个难度层级，题目具有答案和解析，选择题四选项和答案标记合法，示意图引用点存在，网页引用文件存在。

数值抽查包括三边关系的整数计数、勾股定理边长与面积、打印店计费方案在 1～100 页的比较。它们不等于对所有题目数学推理进行了自动证明。

执行 `node work/check-offline.mjs`：离线 HTML 内含 10 段脚本（含新增 PDF 导出器），脚本语法通过，无外部样式或脚本依赖，包含打印功能。

浏览器检查过：题库加载、题型入口、选题、练习卷设置、学生卷预览不出现练习答案、家长卷预览包含答案与步骤、界面日志无错误。WebMCP 接口可加入有效题号、返回选题，拒绝无效题号。检查过手机宽度下的节次选择器与页面宽度。

## 归档导出验证

`scripts/export-data.mjs` 从应用数据文件生成 JSON 与 SQL。SQL 用 Python 标准库 sqlite3 导入内存数据库后检查完整性、外键、章节数、节次数、题型数、例题数和练习数。

GitHub 上传以文件清单中的 Git blob SHA-1 与远端树逐项比较，确认源文件及归档没有在传输时截断或改写。上传清单自身不纳入自身哈希，避免循环依赖。
