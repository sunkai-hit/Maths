# 验证记录与边界

## 当前自动校验

运行：

```bash
npm test
```

会依次执行：

```text
node work/validate.mjs
node work/check-offline.mjs
node scripts/test-pdf.mjs
```

### `work/validate.mjs`

当前结构规则：

- 六章、教材节次和各章综合复习入口均必须有题型；
- 题型 ID、可选题目 ID、代表题 ID 不得重复；
- 一个题型允许任意数量题目，但至少有 1 道可选题；
- 题目必须具有题干、答案和非空解析步骤；
- 选择题必须有 4 个互不重复的选项，答案必须为 A/B/C/D；
- 运行数据不得再包含 `difficulty` 字段；
- 结构化示意图的线段引用点必须存在；
- 第一章带 `figureId` 的题目必须能够解析为 `data:image/...` 原材料题图；
- 第一章题干只要包含“如图”，必须保留原材料题图；
- 第一章每道可选题必须保留 `source` 来源标签；
- 第一章固定校验为 **28 个知识点/专题、90 道可选原材料题目、75 道原材料题图**；
- `dist/index.html` 引用的本地文件必须存在，并且不能继续加载旧 `chapter1a.js`。

另外对第一章三边关系题、手拉手等边模型和专题三第 15 题做定点核对，其中半角模型第 15 题必须包含 `1/2∠BAD` 条件。

### `work/check-offline.mjs`

重新执行 `npm run build:offline` 后，离线 HTML 应包含当前 24 段内联脚本，无外部 CSS/JS 依赖，并包含：

- 第一章完整专题题库；
- `chapter1Figures` 原材料题图数据；
- 打印样式与 `window.print()`；
- 不再出现难度筛选按钮。

### `scripts/test-pdf.mjs`

对全册当前可选题目进行：学生卷/答案卷 × 是否附知识点代表题 × 三档作答留白，共 12 组布局测试，并增加超长题目边界测试。

检查内容包括：

- 每道题恰好出现一次；
- 学生卷不出现练习答案，答案卷包含相应答案；
- 原材料 `figure` 和结构化 `diagram` 数量与布局输出一致；
- A4 可打印区域内无越界和内容重叠；
- PDF 二进制 stream 长度与 xref 偏移正确。

浏览器真正生成 PDF 时，`PaperPDF.create` 会预加载题目的本地 data URL 原图，并按原始宽高比例绘制到 A4 页面。

## 2026-09-12：第一章全量材料重构

第一章最初为了适配旧产品结构，被压缩为每个题型固定三道“基础/提高/压轴”练习，并把部分带图题改写成纯文字条件。根据后续确认，本轮已经改为以下基线：

- **删除难度标签、难度筛选和难度统计**；
- 题型支持任意数量练习；
- 对用户提供 PDF 中的正式题目重新逐节、逐专题盘点；
- 当前第一章为 **28 个知识点/专题、90 道可选原材料题目**；
- 90 道中包括专题二手拉手模型部分的 3 道完整讲解例题（等腰、等边、等腰直角），它们具有完整条件和结论，因此作为正式可选题保留；
- 后半部分答案区出现的同一原题不重复入库，仅作为答案与解析来源；
- 第一章共有 **75 道带原材料图示的可选题**；原图从 PDF 中提取，以题目 ID 为键保存在 `chapter1-figures-1.js`～`chapter1-figures-7.js`；
- `app.js` 在题卡和答案弹窗显示原图，打印页面使用同一图像；
- `pdf-export.js` 增加原图预加载和等比例 Canvas 绘制；
- 第一章专题三第 15 题通过原页图核对，条件确认为 `∠EAF = 1/2∠BAD`。

当前全册运行源码预计为 **70 个知识点/专题、216 道可选题目**。其中第一章按完整材料整理，第二至第六章仍沿用既有内容，只是应用层已统一取消难度标签。

## 结构化导出

`scripts/export-data.mjs` 当前加载完整第一章题库与题图，生成 schemaVersion 2 的 `data/question-bank.json` 和新的 SQLite 兼容 SQL。

SQL `questions` 表不再保存 difficulty，而增加：

- `source`
- `figure_id`
- `figure_json`
- `diagram_json`

JSON / SQL 是运行题库的导出快照，不是网页运行依赖。每次更新源码后需要在本地执行 `npm run export:data` 才会刷新。

## 仍需人工检查的范围

自动校验不能代替完整教研审核，以下内容仍应人工抽查：

- 每一道几何图与题干的点位、标注是否视觉上完全对应；
- PDF 在不同系统字体、浏览器、打印机上的最终视觉效果；
- 扫描材料中极少数 OCR 不稳定符号是否存在未发现的识别误差；
- 第二至第六章后续若切换到“完整材料 + 原图”模式，需要按第一章相同规则重新盘点。

项目仍无后端数据库与多用户同步；这些不属于当前静态题库版本范围。
