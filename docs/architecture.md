# 架构与数据说明

## 运行方式

纯静态 HTML / CSS / JavaScript；无构建框架、无第三方运行依赖、无后端接口。`dist/` 同时是开发源文件目录与静态托管目录。`outputs/` 的单文件版本通过内联样式和脚本生成。

## 文件职责

- `dist/index.html`：网页入口、基础布局、脚本加载顺序。
- `dist/style.css`：桌面、手机、弹窗、A4 打印样式。
- `dist/data.js`：六章目录、题目构造器 `Q`、题型注册器 `TID` / `T`。
- `dist/chapter1a.js`～`chapter1d.js`：第一章完整题库，按基础知识、全等判定、尺规/测距、专题方法拆分。
- `dist/chapter2.js`～`chapter6.js`：第二至第六章题库。
- `dist/reviews.js`：六章综合复习题。
- `dist/diagrams.js`：SVG 数学示意图及题目图形数据。
- `dist/app.js`：筛选、例题与解析、选题草稿、题序调整、打印预览和 WebMCP 接口。
- `dist/pdf-export.js`：A4 分页、Canvas 文字与数学图形绘制、离线 PDF 编码。

## 数据结构

每个题型包含章、节标识、题型名称、知识要点、方法、易错点、一个讲解例题和三个层级的练习。题目包含类型、题干、答案、步骤、选项及可选示意图。练习题 ID 由题型 ID 加 `-1`、`-2`、`-3` 组成，SQL 导出给例题增加 `-example`。

为兼容旧浏览器草稿，原第一章核心题型继续使用 `t01`～`t07`；本次依据完整第一章材料新增的题型使用 `c1-01`～`c1-15`。第二章及后续仍从 `t08` 继续，因此扩充第一章不会导致后续章节既有题号整体漂移。

`data/question-bank.json` 保留完整对象。`database/question-bank.sql` 将对象拆成：

| 表 | 含义 |
| --- | --- |
| `chapters` | 6 章教材顺序 |
| `sections` | 26 个教材节次和 6 个单元复习入口，复习的 section_no 为 0 |
| `topics` | 当前 64 个题型及知识、方法、易错信息 |
| `questions` | 当前 64 道例题和 192 道练习；选项、步骤、图形保存在 JSON 文本列 |

第一章当前包含 22 个题型、22 道例题和 66 道分层练习。第一章材料中的 `1.5 本章专题` 为兼容既有五节导航，映射到第一章的 `1.0`“单元复习”入口；`1.3` 后部的尺规作三角形映射到项目既有 `1.4 三角形的尺规作图`；材料中的 `1.4 利用三角形全等测距离` 映射到项目 `1.5`。

SQL 开启外键约束，可以导入 SQLite。它是便于迁移的数据快照，未接入当前网页运行流程。

## 浏览器草稿

localStorage 键为 `xunti-paper-v1`，保存选中题号、卷标题和留白设置。没有云端同步；本次归档不读取或上传浏览器存储内容。所有题库内容本身已完整随源码和导出文件保存。

## 打印

由同一组选题生成学生卷或答案解析卷。「打印」在点击事件中同步调用 `window.print()`，打印前填充专用容器并关闭模态弹窗，结束后恢复弹窗；`beforeprint` 同时支持浏览器打印快捷键，CSS `@media print` 只显示专用打印容器。宿主浏览器不提供打印窗口时，用户可选择独立下载 PDF。

「排版预览」和「下载 PDF」通过 `PaperPDF.create` 获取选题快照并生成文件，完全不依赖打印对话框和网络。布局器按 A4 页边距、题干长度、选项、图形、作答留白与解析换页，尽量保持一道题完整；超长内容逐行续页。例题与练习分开起页。

Canvas 以 3 倍 PDF 点尺寸绘制中文与数学图形（约 216 dpi），页面 JPEG 作为 PDF 1.4 图像对象写入，按二进制字节长度计算 stream 和 xref。预览复用同一组页面图像，PDF 通过带 download 属性的链接保存，不上传选题。生成进度和失败重试均在界面显示。

PDF 是高清图像页，不能直接选择或检索文字；预览保留可复制的 HTML 文字版。生成整册长卷时，内存和文件大小随页数增长。原生浏览器打印采用 HTML 排版，分页可能与 PDF 不同。

## 开发与迁移

编辑题库后先运行 `npm test`；更新导出文件时运行 `npm run export:data` 和 `npm run build:offline`。新增第一章题型应优先使用 `c1-*` 固定 ID；后续章节继续使用 `T()` 自动分配既有 `t08` 之后的序列，以兼容历史草稿。

`work/package.mjs` 是原创建环境的历史打包脚本，引用当时电脑上的 Sites 工具路径；不属于通用启动步骤。`.openai/hosting.json` 记录了当时注册的站点，尚未上线，不含账号令牌。
