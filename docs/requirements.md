# 需求确认记录

此文档记录当前已确认的产品要求，不是逐字聊天记录。后续如与早期设计冲突，以本页较新的确认项为准。

## 使用对象与教材

- 主要使用者为家长，学习者为鲁教版五四制初二（七年级）上学期学生。
- 学科为数学，六章依次为：三角形、轴对称、勾股定理、实数、位置与坐标、一次函数。
- 教材一节不一定对应一个课时；页面按知识点/题型继续细分，不强制对应学校固定课时。

## 当前核心流程

1. 家长按教材顺序选择章节和知识点/题型。
2. 可查看知识要点、解题方法、易错提醒与代表题。
3. 页面展示该知识点下的**全部已收录题目**，一个知识点的题量不设固定上限。
4. **不再设置“基础题 / 提高题 / 压轴题”标签，也不提供难度筛选。** 家长根据学生实际情况自行选择题目。
5. 保留选择题、填空题、计算题、证明题、作图题、解答题等形式筛选。
6. 家长可以跨题型、跨章节勾选题目组成练习卷；学生练习卷与家长答案解析卷分开输出。
7. 带图题必须随题目保留准确图示，图示同时用于网页浏览、答案解析、打印和 PDF。

## 第一章材料整理要求

第一章以用户提供的《鲁教七上数学（1三角形）》完整材料为基线，不能再只抽取每个题型的少量代表题。

当前确认规则：

- 知识点讲解中的完整模型例题、巩固训练、尺规作图、利用全等测距离及本章专题中的正式题目均需要归入题库；
- 后半部分答案解析中的重复原题不再重复建题，只用于补全答案与解析；
- 第一章当前盘点为 **28 个知识点/专题、90 道可选原材料题目**；
- 其中 **75 道可选题带原材料图示**；
- 原材料图示优先直接从 PDF 原页提取和裁切，不再用近似的通用几何图替代；
- 每道第一章题目保留来源标识，便于反查原材料；
- OCR 符号有歧义时必须结合原页图和答案区核对，不能仅凭解析文本猜测。专题三第 15 题已按原页确认条件为 `∠EAF = 1/2∠BAD`。

## 内容质量要求

- 首要目标是忠实保留用户提供材料的题目条件、图形、答案和主要解题思路；
- 不为了适配数据结构擅自改造原题或删除图形；
- 可以做必要的数字化排版、数学符号统一和 OCR 错位修正，但不能改变题意；
- 题目应按知识点/题型归类，方便家长自主选题；
- 自动校验负责结构、题数、图示关联、选择题格式等检查，不能替代完整教研审核。

## 实现与部署边界

应用继续保持纯静态 HTML / CSS / JavaScript 架构，无后端服务、在线数据库或账号系统。当前运行题库位于 `dist/*.js`；JSON 与 SQLite SQL 通过脚本导出，用于结构化备份、分析和未来迁移，不是网页当前运行依赖。

组卷草稿只保存在当前浏览器 `localStorage`。题库更新后需要重新执行数据导出、离线单文件构建和测试，使源码、JSON/SQL 与 `outputs` 离线页面保持同步。
