# 需求确认记录

此文档根据本次对话中已确认的需求补记，不是逐字聊天记录。

## 使用对象与教材

- 第一版使用者为家长，学习者为鲁教版五四制初二（七年级）上学期学生。
- 学科为数学，章、节顺序依据用户提供的封面及三张目录照片。
- 六章依次是：三角形、轴对称、勾股定理、实数、位置与坐标、一次函数。
- 教材一节不一定对应一个课时；按内容规划建议课时，不固定学校进度。

## 核心流程

1. 家长按教材顺序选择章节、内容课时和题型。
2. 先看例题讲解，再做同类型练习。
3. 同一知识点、同一题型的练习由基础到提高再到压轴逐步递进。
4. 家长自由选择难度，系统不判断掌握程度，不锁定或自动升级难度。
5. 按选择、填空、计算、证明、作图和其他解答等形式分类整理。
6. 家长勾选多道题组成练习卷并打印；学生卷与家长答案解析卷分开输出。

## 内容质量要求

用户强调题型要全面：覆盖常见考法、条件变化、逆向求解、易错情形及综合应用，不能只更换数字增加题量。首版已经建立全册目录框架，但当前 49 个题型、147 道练习仅是首批内容，后续需要继续补充变式、调整难度并开展教研校核。

## 第一版实现选择

网页可在电脑和手机浏览器使用；主要围绕电脑选题打印。题目为原创同步例题与练习。默认学生卷不显示练习答案，可选附例题讲解。组卷草稿仅在当前浏览器本地保存。

## 后续归档要求

用户在 GitHub 创建 `sunkai-hit/Maths`，要求上传刚刚创建的所有内容，包括创建过程文档、代码、数据库和题库。因此将原有工作文件、离线输出、历史发布快照一起保存，并补充结构化题库及 SQL 导出。当前没有原生后端数据库，不能把新增 SQL 导出表述为已有在线数据库。
