# 第一章《三角形》题库整理说明

本次第一章题库依据用户提供的《鲁教七上数学（1三角形）》完整材料整理。材料包含知识点讲解、巩固训练、全等测距、本章专题及后附答案解析。

## 映射原则

- 保留项目现有五个教材入口：`1.1`～`1.5`，不改动第二章及后续章节的导航编号。
- 材料中的 `1.1 认识三角形`、`1.2 图形的全等`、`1.3 探究三角形全等的条件` 分别归入项目同名节次。
- 材料在 `1.3` 后部讲解的“尺规作三角形”归入项目既有 `1.4 三角形的尺规作图`。
- 材料的 `1.4 利用三角形全等测距离` 归入项目 `1.5 利用三角形全等测距离`。
- 材料的 `1.5 本章专题` 归入项目第一章 `1.0 单元复习` 入口，作为模型与辅助线专题训练。
- 每个应用题型继续保持“1 道讲解例题 + 基础/提高/压轴各 1 道练习”的既有结构；难度标签是为了适配应用筛选而补充的结构化分级，不是原材料的官方难度标定。
- 对依赖原图才能理解、或 PDF 解析时符号位置错位的题目，只做数字化表述和符号统一；答案与主要解题方法以材料答案解析为依据。
