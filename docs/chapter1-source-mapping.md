# 第一章《三角形》题库整理说明

第一章依据用户提供的《鲁教七上数学（1三角形）》完整材料整理。材料包括知识点讲解、巩固训练、尺规作三角形、利用全等测距离、三个专题及后附答案解析。

本轮重构不再把原材料压缩成“每题型 1 道基础 + 1 道提高 + 1 道压轴”。经逐节、逐专题盘点，当前第一章共整理为 **28 个知识点/专题、87 道可选原材料题目**。后半部分重复出现的“答案解析原题”用于补全答案和步骤，不重复建立第二条题目记录。

## 映射原则

- 保留项目现有 `1.1`～`1.5` 五个教材入口，不改变第二章及后续导航编号。
- 材料 `1.1 认识三角形`、`1.2 图形的全等`、`1.3 探究三角形全等的条件` 分别归入同名入口。
- 材料在 `1.3` 后部的“尺规作三角形”归入项目 `1.4 三角形的尺规作图`。
- 材料 `1.4 利用三角形全等测距离` 归入项目 `1.5`。
- 材料 `1.5 本章专题` 归入项目第一章 `1.0 单元复习与综合训练`。
- 一个题型允许挂任意数量题目，不设置基础/提高/压轴标签。
- 每道第一章题目保留 `source`，例如“1.3 巩固训练3 第6题”“专题三 第15题”。
- 对题干含“如图”以及依赖图形才能成立的题目，使用 `figureId` 关联从原 PDF 提取的原题图，不再用文字改写替代图示。
- 答案与主要解题过程以材料后附答案解析为依据；扫描/OCR 出现符号错位时结合原页图核对。专题三第 15 题已按原页确认条件为 `∠EAF = 1/2∠BAD`。

## 原图保留

题图分为一个解析入口和七个数据分片：

```text
dist/chapter1-figures.js
dist/chapter1-figures-1.js
...
dist/chapter1-figures-7.js
```

数据分片以题目 ID 为键保存从 PDF 原页提取的本地图像。第一章题目中的 `figureId` 与这些键一一关联，运行时得到 `figure.src`。网页题卡、答案弹窗、浏览器打印和 PDF 导出均读取相同的题图，不再根据题干重新生成一张近似几何图。

校验脚本会检查：只要第一章题干包含“如图”，必须存在有效的 `data:image/...` 原材料题图；具有 `figureId` 的题目也必须能够解析到实际图像。

## ID 兼容

原项目核心题型 `t01`～`t07` 继续保留。新增主题使用 `c1-*` 固定 ID。第一章题目采用来源型 ID（如 `c1-7-6`、`c1-13-15`），第二章及以后仍延续原有 `t08` 之后的题型编号，避免旧浏览器草稿中后续章节 ID 因第一章扩充而整体漂移。
