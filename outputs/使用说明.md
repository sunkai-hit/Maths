# 循题 · 七上数学家长组卷

用电脑浏览器打开同目录下的「循题-七上数学家长组卷.html」即可使用，不需要安装或联网。

1. 在左侧选择教材章节和节次，再选择内容课时或题型。
2. 点击「例题讲解」查看知识要点、解题方法、易错提醒及例题解析。
3. 在题库选择范围、题目形式和难度，勾选需要的练习。可以跨章节组卷。
4. 点击「我的练习卷」，修改标题、调整题序与作答留白。
5. 输出内容选择「学生练习卷」，点击「排版预览」查看 A4 分页，再点击「下载 PDF」保存文件。也可以直接点击练习卷底部的「下载 PDF」。
6. 点击「打印」可调出浏览器打印窗口。如果当前应用内的浏览器没有弹出窗口，请下载 PDF，用电脑上的 PDF 阅读器打开后打印。
7. 再将输出内容切换为「家长答案解析卷」，单独下载或打印答案和详细解题步骤。

需要先学例题时，可以勾选「附所选题型的例题讲解」，将有关例题放在练习之前。

下载的 PDF 使用固定 A4 分页，包含页码；预览显示的就是 PDF 各页内容。为保证离线环境中的中文和数学符号显示一致，PDF 采用高清页面图像，不能直接选中文字。需要复制时，展开预览下方的「查看可复制的文字版」。浏览器原生打印的分页可能与 PDF 略有不同。

当前内容覆盖六章、26 节及每章复习，共 49 个题型、49 道讲解例题和 147 道练习。每个题型的练习分别对应基础、提高、压轴三个层级。这是首批原创题库，尚未穷尽所有考法与变式；难度分级以题型内的递进为主。教材目录来自提供的照片，课时按内容划分，不代表学校的固定授课安排。

组卷草稿保存在当前浏览器中，清除浏览器数据可能丢失。不同浏览器、电脑和文件位置之间不自动同步。请将重要练习卷打印或保存为 PDF。若浏览器禁止本地文件保存数据，当前页面仍可选题和打印，但关闭后的草稿可能无法保留。

应用不判断学生掌握程度，也不收集学生作答。在线版本尚未发布；离线网页可独立使用。
