# 循题 · 七上数学家长组卷

用电脑浏览器打开同目录下的「循题-七上数学家长组卷.html」即可离线使用，不需要联网。若刚从 GitHub 拉取了最新源码，请先在项目根目录运行 `npm run build:offline`，确保此 HTML 已同步最新题库。

1. 在左侧选择教材章节和节次，再选择知识点或题型。
2. 点击「知识与代表题」查看知识要点、解题方法、易错提醒及代表题解析。
3. 在题库选择范围和题目形式，直接勾选需要的题目；当前版本**不设置基础/提高/压轴难度标签**，由家长自行选择。
4. 带图题会直接显示原材料图示；第一章原图也会随题目进入答案、打印和 PDF。
5. 点击「我的练习卷」，修改标题、调整题序与作答留白。
6. 输出内容选择「学生练习卷」，点击「排版预览」查看 A4 分页，再点击「下载 PDF」保存文件；也可以直接打印。
7. 将输出内容切换为「家长答案解析卷」，可单独下载或打印答案和详细解题步骤。

需要同时复习知识点时，可以勾选「附所选知识点的代表题讲解」，将相关代表题放在练习之前。

下载的 PDF 使用固定 A4 分页并包含页码。为保证离线环境中的中文、数学符号与题图一致，PDF 采用高清页面图像，不能直接选中文字；需要复制时，可展开预览下方的「查看可复制的文字版」。浏览器原生打印分页可能与 PDF 略有不同。

当前运行源码覆盖六章、26 个教材节次及各章综合复习，共 **70 个知识点/专题、216 道可选题目**。第一章《三角形》已依据完整材料整理为 **28 个知识点/专题、90 道可选原材料题目**，其中 **75 道带原材料图示**。

组卷草稿保存在当前浏览器中，清除浏览器数据可能丢失。不同浏览器、电脑和文件位置之间不自动同步。应用不判断学生掌握程度，也不收集学生作答。
