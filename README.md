# Maths · 循题七上数学家长组卷

面向家长的鲁教版五四制数学七年级上册同步题库应用。按教材章节与知识点浏览题目，自主勾选题目组卷，并分别输出学生练习卷和家长答案解析卷。

## 使用

- **本地开发**：安装 Node.js 20+，在仓库根目录执行 `npm start`，打开 `http://127.0.0.1:4173/`。
- **重新导出结构化题库**：`npm run export:data`，刷新 `data/question-bank.json` 与 `database/question-bank.sql`。
- **重新生成离线单文件**：`npm run build:offline`，刷新 `outputs/循题-七上数学家长组卷.html`。
- **运行校验**：`npm test`。

没有第三方运行时依赖，通常不需要执行 `npm install`。应用本身是纯静态 HTML / CSS / JavaScript，无后端服务、账号系统或在线数据库依赖。

## 已实现

- 六章教材目录、26 个教材节次及各章综合复习入口。
- 当前运行源码共 **70 个知识点/专题、213 道可选题目**。
- 第一章《三角形》已按用户提供的完整材料重构为 **28 个知识点/专题、87 道可选原材料题目**，不再人为限制每个题型只能有固定数量练习。
- **取消基础题 / 提高题 / 压轴题标签与难度筛选**，家长按知识点、题目形式和实际学习情况自行选题。
- 第一章带图题保留从原材料提取的题图；题图同时进入网页题卡、解析、浏览器打印和 PDF 导出。
- 支持选择题、填空题、计算题、证明题、作图题、解答题等形式；保留知识要点、解题方法、易错提醒、答案和分步解析。
- 支持当前节、当前章、全册范围筛选；跨章节组卷、调整题序、按题目形式整理。
- 学生卷与家长答案卷分开输出；支持标题、作答留白、是否附知识点代表题等配置。
- 可在浏览器内生成 A4 PDF 与分页预览；中文、数学符号、结构化几何图和第一章原材料题图均离线处理。
- 组卷草稿保存在当前浏览器的 `localStorage`，键为 `xunti-paper-v1`。

## 第一章整理原则

第一章依据《鲁教七上数学（1三角形）》完整材料整理。知识点讲解、巩固训练、尺规作图、利用全等测距以及本章专题中的正式题目均按原材料来源归入相应知识点；后附答案解析用于补全答案与步骤，不重复建立第二份题目。

第一章不再按照“1 道例题 + 基础/提高/压轴各 1 道”的旧结构压缩内容。每个知识点可拥有任意数量题目，每道题保留 `source` 来源标识；带图题通过 `figureId` 关联从原 PDF 提取的原题图。材料中的 `1.5 本章专题` 为兼容现有导航映射到第一章 `1.0 单元复习与综合训练`，材料中的尺规作图映射到项目 `1.4`，材料编号 `1.4 利用三角形全等测距离` 映射到项目 `1.5`。

## 题库与数据库

当前网页直接读取 `dist/*.js`，不连接 JSON 或 SQL。`npm run export:data` 会把同一运行题库导出为 JSON 和 SQLite 兼容 SQL；新 SQL 结构保存题目来源、题型、题干、答案、步骤、选项、`figure_id`、题图数据及结构化示意图。

因此当前仍是纯静态应用：JS 是运行数据源，JSON / SQL 是结构化导出与迁移格式。修改题库后建议依次执行：

```bash
npm run export:data
npm run build:offline
npm test
npm start
```

## 内容边界

第一章以用户提供材料为整理依据，对扫描/OCR 中出现的符号错位会结合原页图和答案区核对；例如专题半角模型第 15 题按原页确认条件为 `∠EAF = 1/2∠BAD`。第二至第六章目前仍为既有题库内容，后续可以使用与第一章相同的“全量题目 + 原图”方式继续扩充。
